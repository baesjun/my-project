## 연구
- 0.25° 일단위 토양수분 예측 모델 (Aardvark Weather 구조 참고).
- 격자 범위: 전지구(남극 제외), 위도 60S–90N, 경도 0–360 (0–360 표기). 격자 크기 [확인 필요].
- ISMN 관측소 일자료는 관측 기반 e2e fine-tuning의 정답 및 평가에 쓰인다.
- 별개 연구(in-situ 센서 온도 기인 일주기 보정, hourly)와 섞지 않는다.

## 입력 파일 (ismn_daily.py 출력)
- 위치: /home/sjbae/aardvark/daily_ismn_csv/*.csv, 파일 1개 = 관측소(센서) 1개
- 열: date_time, latitude, longitude, sm_corrected
- 생성 방식: 시간 자료에서 sm_corrected 결측 제거 → 하루 유효 시간 수 8 이상인 날만 → 일평균
- 따라서 빠진 날 = 원자료가 없거나 유효 시간 수 8 미만인 날. 둘은 이 파일만으로 구분할 수 없다.
- 깊이 정보 열이 없다. 같은 좌표 파일이 여러 개면 깊이·센서 차이인지 [확인 필요].

## 점검 항목과 기준
| 항목 | 기준 | 근거 |
|---|---|---|
| 열 구성 | 위 4개 열 존재 | ismn_daily.py |
| 날짜 | 파싱 가능, 중복 없음, 오름차순 | ismn_daily.py가 정렬해 저장 |
| 좌표 | 파일 내 일정, 위도 -60–90, 경도 0–360(변환 후) 안 | dataset.py는 경도를 0–360으로 변환해 사용 |
| 단위 | 체적함수율 m³/m³ (0–1). 중앙값 > 1이면 % 단위 의심 | ISMN 배포 단위 |
| 범위 | < 0 불가. > sm-max(기본 0.6) 의심 | 0.6은 임시값 [확인 필요] |
| 정체 | 같은 값 연속 flat-days(기본 10)일 이상 | 기본값 [확인 필요] |
| 급변 | 하루 변화량 > jump(기본 0.15) | 기본값 [확인 필요]. 강수 직후 정상 급변 가능 |

## 점검이 필요한 이유
- dataset.py는 sm_corrected에 범위 검사 없이 그대로 쓴다.
- compute_stats.py는 전체 ISMN 값으로 mean/std를 구해 정규화에 쓴다. 단위가 다른 파일이 섞이면 정규화 통계가 달라진다.
